# Anime Badge Maker Skill

[Repository documentation](../../README.md) | [中文文档](../../README.zh-CN.md)

This folder is the installable Agent Skill. Copy it as one directory; do not copy `SKILL.md` alone because the workflow also uses the quality checklist, references, UI metadata, and blank physical badge asset.

此目录是可直接安装的完整 Agent Skill。请整体复制，不要只复制 `SKILL.md`，因为工作流还会使用质量清单、参考文档、界面元数据和空白实体徽章素材。

Default invocation / 默认调用：

```text
Use $anime-badge-maker to make my uploaded references into badge artwork and a physical mockup.

使用 $anime-badge-maker 按徽章标准制作我上传的参考图。
```
