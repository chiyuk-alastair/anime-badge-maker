# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-08

### Added

- Two-stage workflow for circular anime badge artwork and physical badge mockups.
- Automatic task routing for artwork-only, mockup-only, and full workflows.
- Subject ownership analysis to prevent foreign limbs and props from entering the character design.
- Identity, anatomy, composition, and physical-compositing quality gates.
- Generic blank physical badge asset created for the public release.
- English and Simplified Chinese project documentation.
